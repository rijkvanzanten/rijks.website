# Stuff I(’ve) Work(ed) On

These days I spend most of my time working on Directus ([directus/directus](https://github.com/directus/directus)) and Monospace ([monospace.io](https://monospace.io)).

I teach the Typography & Interaction course in [the MPS CD program](https://www.newschool.edu/parsons/mps-communication-design/) of which the syllabus is published here: [typography-interaction-2526.github.io](https://typography-interaction-2526.github.io/)

Outside of that, I maintain and/or contribute to a number of other projects, including but not exclusive to:

- [knex/knex-schema-inspector](https://github.com/knex/knex-schema-inspector)\
  Utility for extracting normalized database schema information through Knex.
- [directus/vue-split-panel](https://github.com/directus/vue-split-panel)\
  Vue component for building resizable split-pane interfaces.
- [typography-interaction-2425/ti-preview](https://github.com/typography-interaction-2425/ti-preview)\
  Web component for interactively editing and previewing code.
- [rijkvanzanten/coverage-change-action](https://github.com/rijkvanzanten/coverage-change-action)\
  GitHub Action reporting test-coverage changes for files modified by a pull request.
- [rijkvanzanten/rolling-wave-engineering](https://github.com/rijkvanzanten/rolling-wave-engineering)\
  My custom skills framework for agentic software development.
